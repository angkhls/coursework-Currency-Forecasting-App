# Спецификация требований проекта Currency Forecasting App

## 1. Бизнес-требования

### BR-01. Назначение системы
Система должна обеспечивать пользователю доступ к актуальным данным по валютным курсам и предсказанию их изменения на основе исторических данных.

### BR-02. Проблема, которую решает система
Пользователь, работающий с валютными операциями или анализом рынка, обычно вынужден проверять несколько источников данных и вручную оценивать тренды. Приложение объединяет данные, графики и прогнозы в одном интерфейсе.

### BR-03. Цели проекта
- обеспечить быстрый доступ к курсам валют;
- показать изменение курса по периодам;
- дать пользователю прогноз на основе статистической модели;
- предоставить удобный интерфейс для конвертации и анализа;
- снизить время на подготовку решения по валютным операциям.

### BR-04. Ожидаемый эффект
Пользователь получает единую рабочую среду для мониторинга валютных курсов, анализа динамики и оценки вероятного направления движения цены.

## 2. Пользовательские требования (Use Case)

### UC-01. Просмотр актуального курса валют
Пользователь открывает главную страницу и видит текущие курсы валют.

### UC-02. Выбор валютной пары
Пользователь выбирает пару, например USD/BYN или EUR/BYN, для детального анализа.

### UC-03. Просмотр истории изменения
Пользователь просматривает график исторических значений курса за период.

### UC-04. Анализ прогноза
Пользователь получает прогноз по будущему движению курса на основе модели.

### UC-05. Конвертация суммы
Пользователь вводит сумму и выбирает валюты для перевода.

### UC-06. Просмотр новостей рынка
Пользователь открывает секцию новостей, связанную с валютным рынком.

### UC-07. Сравнение технических индикаторов
Пользователь видит SMA, EMA и уровни поддержки/сопротивления.

## 3. Функциональные требования

### FR-01
Система должна отображать актуальные курсы валют на главной странице.

### FR-02
Система должна поддерживать выбор валютной пары для подробного анализа.

### FR-03
Система должна предоставлять историю курса за выбранный период.

### FR-04
Система должна отображать график изменения курса по времени.

### FR-05
Система должна рассчитывать прогноз курса для выбранной валютной пары.

### FR-06
Система должна использовать модель SARIMAX или аналогичный статистический метод для прогнозирования.

### FR-07
Система должна рассчитывать и показывать SMA(20).

### FR-08
Система должна рассчитывать и показывать EMA(20).

### FR-09
Система должна показывать уровни поддержки и сопротивления.

### FR-10
Система должна рассчитывать метрики MAPE и RMSE для оценки качества прогноза.

### FR-11
Система должна обеспечивать конвертацию суммы из одной валюты в другую.

### FR-12
Система должна использовать курсы НБРБ в качестве основного финансового источника данных.

### FR-13
Система должна хранить историю котировок в выбранной базе данных.

### FR-14
Система должна отображать ленту новостей по финансовой тематике.

### FR-15
Система должна поддерживать запросы к API для получения данных и прогноза.

### FR-16
Система должна возвращать ошибки API в понятном виде при сбое внешнего сервиса.

### FR-17
Система должна быть доступна для запуска как из локального окружения, так и через контейнеры.

### FR-18
Система должна поддерживать работу с несколькими валютными парами: USD/BYN, EUR/BYN, RUB/BYN, CNY/BYN, GBP/BYN, PLN/BYN, AED/BYN, CHF/BYN, UAH/BYN, TRY/BYN.

## 4. Нефункциональные требования

### NFR-01
Система должна обеспечивать отклик API в течение не более 3 секунд для стандартных запросов к истории и данным.

### NFR-02
Система должна корректно работать в последних версиях Chrome, Edge и Firefox.

### NFR-03
Интерфейс должен корректно отображаться на экранах мобильных устройств и десктопов.

### NFR-04
Система должна поддерживать разделение логики на уровни: API, service, domain, infrastructure.

### NFR-05
Система должна обеспечивать отказоустойчивость при временной недоступности внешнего API.

### NFR-06
Код должен быть структурирован и тестируем, чтобы можно было добавлять новые валютные пары и типы прогнозов без переписывания ядра.

## 5. Критерии приемки

- пользователь может открыть главную страницу и увидеть актуальные курсы;
- пользователь может выбрать валютную пару и просмотреть историю;
- пользователь может получить прогноз по выбранной паре;
- пользователь может отразить конвертацию суммы;
- пользователь может открыть новости и просмотреть графики;
- система корректно отображает ошибки при недоступности данных.
