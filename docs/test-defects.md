# Отчёт о найденных дефектах — задание 3.5

## DEF-01: Вызов несуществующего метода get_latest_date в RateService.sync_rates
- Краткое описание: При вызове синхронизации курсов возникала AttributeError.
- Ожидаемый результат: POST /api/v1/rates/USD/sync вызывает repository.get_latest(currency) и возвращает HTTP 200.
- Фактический результат: В forecasting/service/rate_service.py вызывался get_latest_date(currency), возвращался HTTP 502.
- Требование: FR-12, FR-13, FR-01, TC-08.
- Шаги воспроизведения: Запустить backend и отправить POST /api/v1/rates/USD/sync.
- Воспроизводимость: Всегда (100%).
- Важность и срочность: High / High.
- Симптом: HTTP 502 при синхронизации курсов.
- Возможность обойти: Заменить get_latest_date на get_latest (исправлено).
