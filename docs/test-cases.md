# Тест-кейсы — задание 3.3

> Документ содержит набор тест-кейсов, разработанных на основании чек-листа функциональных требований. Требования привязаны к FR-01…FR-18, а также к пользовательским сценариям из [docs/requirements.md](requirements.md). Этот документ описывает тесты, но не заменяет фактический отчёт выполнения: статусы, дата, окружение, скриншоты и видео фиксируются в [docs/test-execution.md](test-execution.md).

## 1. Условные обозначения

- Приоритет: High / Medium / Low
- Требование: ссылка на функциональное требование из `docs/requirements.md`
- Модуль: компонент/приложение, где наблюдается поведение
- Исходные данны��: минимальный набор данных для запуска проверки
- Шаги: последовательность действий
- Ожидаемый результат: контролируемый результат проверки

## 2. Набор тест-кейсов

### TC-01. Dashboard показывает актуальные курсы
- ID: TC-01
- Приоритет: High
- Связанное требование: FR-01, FR-12, FR-18
- Модуль/подмодуль: API + Dashboard UI
- Заголовок: Отображение актуальных курсов валют на главной странице
- Исходные данные: в хранилище есть курсы для USD, EUR, RUB, TRY и поддерживаемые пары; backend запущен
- Шаги:
  1. Открыть главную страницу `/`.
  2. Проверить вывод валютных курсов в верхней панели/карточках.
